---
title: Errors
description: JSON error envelope used by the public API.
---

Failed requests return:

```json
{
  "error": "Human-readable message",
  "code": "UNAUTHORIZED"
}
```

| Status | Code | When |
| --- | --- | --- |
| 400 | `INVALID_REQUEST` | Zod validation failed |
| 401 | `UNAUTHORIZED` | Missing/invalid API key or Magica 401 |
| 402 | `CREDITS_INSUFFICIENT` | Not enough reserved credits |
| 404 | `CHAT_NOT_FOUND` / `RUN_NOT_FOUND` / `UNKNOWN_TOOL` | Ownership hide or unknown Magica tool |
| 409 | `RUN_ACTIVE` | Another turn is running in the chat |
| 429 | `RATE_LIMITED` | Send window exceeded; `Retry-After` is set |
| 504 | `TIMEOUT` | Magica poll timed out |

Long-running agent turns do not use HTTP 504. They stay `queued` until you poll `/runs/{runId}`.
