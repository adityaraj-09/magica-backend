---
title: Send is blocked
description: Only one active run per chat.
---

Each chat has **one active run**. A second send returns `RUN_ACTIVE` instead of starting duplicate work.

## What to do

- Wait for Thinking… / Working… to finish
- Stop the run if you want to change direction
- Start a **new task** if you need a second job in parallel

Plan-mode and credit waitpoints also hold the run in `WAITING`. Approve or reject the card, or wait for it to expire, then send again.
