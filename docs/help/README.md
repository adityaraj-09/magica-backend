# Galaxy Help Center (Mintlify)

Product help, separate from the public API docs in `backend/docs`.

## Local

```bash
npx mintlify dev
```

Run this from `doc/help`.

## Deploy

Host this folder as a second Mintlify site (same pattern as [Galaxy Agent API](https://magica-adi.mintlify.site/)). Point the sidebar **Help & Support** item at that URL when the site is live.

Topics follow the [Magica Help Center](https://magica.com/helpdesk) groups, written for what this product actually supports.
