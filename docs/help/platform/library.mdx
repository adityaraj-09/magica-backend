---
title: What is the Library?
description: Workspace collection of uploaded and generated files.
---

The Library is your collection of generated and uploaded assets.

Use it to preview, favorite, reuse, or download images and files. Open **Library** from the sidebar, or open the same browser in a dialog when you attach a file to a new task.

## Library, task files, and project context

| Location | What it contains | Best use |
| --- | --- | --- |
| Library | Uploads and generated assets across your account | Store and reuse media |
| All files in this task | Uploads and generated assets for the current chat | Review one conversation |
| Project instructions / memory | Text context for every task in a project | Keep voice and facts, not files |

Memory is different from file storage. Memory keeps useful facts. It is not a replacement for uploading a source document.

## Use a Library asset in a task

1. Click attach in the composer.
2. Choose an existing Library asset.
3. The composer shows a thumbnail, the same as a fresh upload.

Library content is scoped to the signed-in account.
