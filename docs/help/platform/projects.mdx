---
title: What are Projects?
description: Bundle related tasks with shared instructions and optional memory.
---

Projects bundle related tasks together with shared context. Use a project when you want Galaxy to keep a consistent persona or accumulated notes across many chats — for example, all your marketing work or research on a topic.

Open **Projects** from the left sidebar.

## What a project has

- **Name and icon** — how it appears in the list
- **Instructions** — applied to every task in the project
- **Memory** — optional notes from earlier turns, injected only when memory is on

To create one, click **New project**, pick a name and icon, and choose whether memory is enabled. Start a task from the project workspace so it inherits that context.

## How memory works

When memory is on, Galaxy appends a short note from finished turns (capped) and shows **% of memory used**. Instructions always apply when they are set. Memory notes apply only if memory is enabled.

<Note>
  Memory is not a replacement for uploading a source document. Put files you need in the task or Library.
</Note>
