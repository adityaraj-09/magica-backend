Open **Settings** from the sidebar pills (or your avatar).

## Account

Your signed-in profile, email, and credit balance.

## General and preferences

Theme (system, light, dark) and the same toggle that sits in the sidebar.

## API keys

Create and revoke `gxk_live_…` keys for the public REST API and MCP. The full key is shown once. You can also manage keys from **Settings → API Keys → Manage**.

Developer reference: [https://magica-adi.mintlify.site/](https://magica-adi.mintlify.site/)
