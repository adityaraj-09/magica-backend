---
title: What can Galaxy do?
description: Tasks Galaxy is best at, and when to use chat, tools, or the API.
---

Galaxy handles creative, research, and media work in one chat. It is strongest when a task is multi-step, uses an uploaded file, or needs a finished image or video instead of a text-only answer.

## Tasks Galaxy is well suited for

- explain or compare a topic and write a clear reply
- generate or edit an image with GPT Image 2
- crop an image to a rectangle
- merge videos with none, fade, or dissolve
- search the web when the answer needs current sources
- run short Python in the sandbox
- load a skill and follow its steps
- keep related work together in a Project

## Choose the right surface

| Your goal | Best place to start |
| --- | --- |
| Complete a one-time or open-ended task | **New task** |
| Reuse files, instructions, or memory | **Projects** |
| Pick a model or tool yourself | **Tools** |
| Call Galaxy from your software | **API** |
| Let an MCP client use Galaxy | **MCP** |

If you are not sure, start a new task. Use Tools when you already know the capability. Use [API / MCP](https://magica-adi.mintlify.site/) for developer access.

<Note>
  The agent may ask you to approve a plan or extra credits before tools run. Review generated media before you reuse it.
</Note>
