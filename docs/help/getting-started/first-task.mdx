---
title: Complete your first task
description: Sign in, send a message, and read the live run.
---

<Steps>
  <Step title="Open New task">
    From the sidebar, click **New task**. Sign in if you are asked.
  </Step>
  <Step title="Write the outcome">
    Type what you want. Attach an image or pick one from the Library if the task is about a file.
  </Step>
  <Step title="Send">
    Galaxy creates the chat, opens `/chat/{id}`, and shows Thinking… or Working… until text or a tool card arrives.
  </Step>
  <Step title="Watch the turn">
    Text streams as the model writes. If GPT Image 2 starts, the tool card shows the prompt while the image generates.
  </Step>
  <Step title="Continue or stop">
    Send another message in the same task, or stop the run if you want to change direction. One chat can only have one active run at a time.
  </Step>
</Steps>

<Note>
  If send is blocked with a running-task error, wait for the current run to finish or stop it from the chat.
</Note>
