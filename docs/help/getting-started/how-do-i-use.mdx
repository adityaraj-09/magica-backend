---

Start with **New task** and describe the result you want. You do not need to choose every tool or plan every step.

## Give a useful brief

Include:

- the outcome you want
- relevant context or source files
- the intended audience
- the format you need
- important limits or actions to avoid

For example:

> Research five competitors for my US accounting software, compare their positioning, and create a concise sales brief with source links. Do not contact anyone.

## Review and continue

The agent chooses tools when they are required, then streams the reply in the same task. You can change direction, attach more files from the Library, or ask it to revise the result.

Use **Plan mode** when you want to review the approach before tools run. Use a **Project** when several tasks should share instructions or memory.

## After the reply

The row under a finished assistant message shows:

- the time of the message
- how long the run took
- prompt + completion tokens from OpenRouter
- application credits charged for that turn
- the routed model
