---
title: What data does Galaxy store?
description: Conversations, files, projects, and how you can remove them.
---

Galaxy stores the information needed to provide the features you use. This can include:

- task conversations and attached files
- Projects, instructions, and project memory
- generated and uploaded Library assets
- account settings, theme, and API key metadata (not the raw key after you copy it)
- credit ledger rows for a run

Your exact data depends on which features and files you use.

## Controls available to you

- Delete tasks you no longer need
- Delete Library assets
- Turn project memory off or clear project instructions
- Revoke API keys
- Download generated media you want to keep

<Note>
  OpenRouter and Magica see the content required to complete a turn (prompt, images, tool payloads). Do not paste secrets you would not send to those providers.
</Note>
